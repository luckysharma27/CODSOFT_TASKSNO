# How to Test Task 5

## Webcam
1. Run: py -3.13 face_detection.py
2. Enter 1.
3. Allow camera access if Windows asks.
4. A rectangle should appear around detected faces.
5. Press q to close the camera.

## Image
1. Run the program.
2. Enter 2.
3. Enter the full path of an image containing faces.
4. Rectangles will appear around detected faces.
5. Press any key to close the image window.
