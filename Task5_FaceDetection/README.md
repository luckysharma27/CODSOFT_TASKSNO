# CODSOFT AI Internship - Task 5

## Face Detection System

### Objective
Build an AI-based face detection system that detects human faces in an image or through a webcam.

### Technologies Used
- Python
- OpenCV
- Haar Cascade Classifier
- Computer Vision

### Features
- Webcam face detection
- Image face detection
- Rectangle around detected faces
- Displays number of detected faces
- Simple menu interface

### Installation
```bash
pip install -r requirements.txt
```

For Python 3.13:
```bash
py -3.13 -m pip install -r requirements.txt
```

### Run
```bash
py -3.13 face_detection.py
```

Choose `1` for webcam, `2` for an image, or `3` to exit.

In webcam mode, press `q` to close the camera window.

### Learning Outcomes
- Computer vision
- Face detection
- OpenCV
- Haar Cascade classifiers
- Image preprocessing
- Webcam handling
