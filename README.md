# CODSOFT Artificial Intelligence Internship

This repository contains the projects completed during my CodSoft Artificial Intelligence Internship.

## Tasks

### Task 1 - Rule-Based Chatbot
A simple chatbot that responds to user inputs using predefined rules and conditional statements.

### Task 2 - Tic-Tac-Toe AI
An AI-based Tic-Tac-Toe game where the computer plays against the user using the Minimax algorithm.

### Task 3 - Movie Recommendation System
A content-based movie recommendation system that compares movie genres and descriptions to recommend similar movies.

### Task 4 - Image Captioning
An AI-based image captioning system that uses a pretrained BLIP model to generate descriptions for images.

### Task 5 - Face Detection
A computer vision application that detects faces in images and through a webcam using OpenCV and Haar Cascade.
